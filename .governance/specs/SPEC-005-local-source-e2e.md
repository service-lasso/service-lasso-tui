# SPEC005: ordinary-source local TUI E2E

Issue #42, parent #1. This is a reproducible ordinary source/backend test lane, distinct from all selected native profile, custody, publication and full operator acceptance gates.

## E2E001 Inputs and provenance
Build the TUI from the exact clean checkout with Go1.26.0, empty GOFLAGS and GOWORK=off. Record revision and binary SHA256. Connect only to a separately owned disposable real Core using a private mode600 connection file and an explicit source/build or installed-artifact SHA receipt. Require source-built classification, clean source/tree/input inventory, compiler/tool/dependency identity, successful build and initialized API; verify final cleanup receipt and independent port refusal. No hidden historical Core substitution or token in argv/public evidence. The Core owner retains backend startup/shutdown; an externally supplied backend must be explicitly identified as such.

## E2E002 Real terminal
POSIX ordinary source PTY probes wait for actual healthy compatibility UI or safe v2 unavailable UI before any key (package-init OSC query may take five seconds). Verify raw ICANON, actual help transition, Escape dashboard return, narrow/navigation/reconnect, resize and natural q exit with actual waitpid. EOF/EIO closes only the stream; it never substitutes for the original child wait deadline. Authentication-negative identity must not acquire actual local-token status; supported loopback local-root fallback is not an access-denial claim. Guarded OAuth/lifecycle permission denial remains a separate blocked obligation. Reconnect binds actual increased successful health/services request counts.

## E2E003 Outcomes and cleanup
Compatibility PASS, v2 functional PASS, v2 unavailable and unsupported-platform are separate results. Missing v2 route never passes full operator acceptance. Preserve private raw streams at0600; public summary contains only closed outcomes, provenance, timing and token-leak Boolean. Always retain live child ownership through failed stages and use normal documented interrupt before any explicit unresolved cleanup outcome. No synthetic token or native profile can establish backend/native acceptance. Windows ConPTY is a separate matching-host obligation; macOS POSIX coverage remains separately reported, not borrowed Linux proof.

## E2E004 Repeatability
One documented runner and dedicated workflow execute bounded source tests and the real-backend terminal lane when authentic backend inputs exist. Tests exercise readiness, EOF-before-reap, bad provenance/auth and public redaction. Exact source/build/backend identities and exit results accompany evidence. Existing native CI gates remain unchanged.
