# Declared action inspection

Current operator/v2 source behavior, UNRUN. This does not qualify a compiled or
installed candidate, backend authority, publication or native acceptance.

Select an action in `declared_actions`, then use `Alt+PgUp` or `Alt+PgDn` to
inspect its admitted declaration without creating a payload draft. `Up`/`Down`
move through wrapped lines; `Alt+PgUp`/`Alt+PgDn` move through pages.
`Alt+Home` or `Escape` returns to action selection. `r` refreshes the read.
`Enter`, `e` and payload edit gestures create no mutation while inspecting.

The inspector shows the actual payload policy, required profile/scopes,
declared permission, action availability, schema node types, root, property
edges, required properties, array-item edges and supplied supported constraints.
Enum values are withheld; their declared count is shown. Reference labels and
availability are visible, while opaque reference tokens remain withheld.
An absent schema, unavailable schema and unsupported schema are distinct.
No payload input, default value, arbitrary path or raw error is synthesized.

Inspection uses the current successful form selection. Foreign service/context,
failed reads and pending reads cannot supply inspection lines. It keeps action
row indexing and fetched bytes intact, including during retained request
uncertainty. Resize uses the physical viewport and resets review position.

Schedules, concurrency and failure-policy metadata are unavailable in the
current DTO and remain a Core successor dependency. Inspection is read-only
and supplies no execution or reference authority. All original source review,
diagnostic capture, finite owner, installed-byte and Windows/Linux native
acceptance requirements remain pending.
